# Карта и редактор карт RolyPoly

## Офлайн-подложка
Карта мира работает полностью автономно на базе `world-atlas` (`countries-50m.json`) и `topojson-client` без обращения к внешним серверам тайлов или API.
Доступные цветовые схемы: **Тёмная**, **Рельеф**, **Серая**, **Сетка**.

## Слои карты
1. **Политическая** — окраска по цвету государства-владельца.
2. **Физическая** — оценка ресурсов и заселённости территории.
3. **Экономическая** — градация по численности населения.
4. **Дипломатическая** — союзники, враги и напряжённость относительно выбранного/своего государства.
5. **События** — территории, затронутые игровыми событиями.
6. **Контроль** — контролируемые и нейтральные территории.

## Инструменты редактора (только для Ведущего)
- **Импорт GeoJSON** — массовая загрузка территорий в игровую сессию.
- **Подложка (PNG/JPG/SVG/WebP)** — наложение исторической или пользовательской карты поверх рабочей области с регулировкой прозрачности.
- **Рисование полигона** — пошаговое создание новой территории с поддержкой `Undo`/`Redo` и автосохранением черновика в `sessionStorage`.
- **Правка границ** — перетаскивание вершин выбранной территории.
- **Объединение** — слияние двух территорий через `@turf/turf` (`union`).
- **Разделение** — разрез выбранной территории линией из 2+ точек на несколько частей.
